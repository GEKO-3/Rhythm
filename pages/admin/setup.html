Admin User Setup

Setup Instructions:

  1. First, create Firebase Authentication users in the Firebase Console
  2. Go to Authentication → Users → Add User
  3. Create users with email and password
  4. Copy the User UID from Firebase Console
  5. Use this form to set up admin permissions in the database

Note: Users must be created in Firebase Authentication first, then configured as admin here.

Default Admin Emails (if you choose to set up defaults):

  • admin@rhythmboduberu.com
  • manager@rhythmboduberu.com

Important: You must create these users in Firebase Authentication first!
