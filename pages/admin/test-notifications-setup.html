📋 Quick Setup (5 minutes)

1 Download Service Account Key

You need a Firebase service account key to send notifications from your computer.

  1. Click the button below to open Firebase Console
  2. Click "Generate New Private Key"
  3. Save the file as serviceAccountKey.json in your project root folder
  4. Location: /Users/ahmedjazlaanshareef/Dev/Rhythm/serviceAccountKey.json
Open Firebase Console →

⚠️ SECURITY WARNING:

  • This file gives full admin access to your Firebase project
  • Never commit it to git (already in .gitignore)
  • Never share it with anyone
  • Keep it secure on your computer only
2 Run the Test Script

Open Terminal and run:

cd /Users/ahmedjazlaanshareef/Dev/Rhythm
npm run test-notification

Or directly:

node send-test-notification.js
3 Follow Interactive Prompts

The script will:

  • 📋 Load all members from database
  • ✓ Show which members can receive notifications
  • 👤 Let you select a member
  • ✍️ Ask for notification title and body
  • 📤 Send the notification immediately!

✅ Pre-Testing Checklist

  • User has the PWA app installed
  • User has logged in at least once
  • User clicked "Allow" for notifications
  • User's FCM token exists in database
  • serviceAccountKey.json downloaded and placed in project root

🔍 How to Check if User Has Token

  1. Go to Firebase Database Console
  2. Navigate to: members → {memberId} → fcmToken
  3. If fcmToken exists → User can receive notifications ✅
  4. If no fcmToken → User needs to enable notifications ❌

🐛 Common Issues

Cannot find module 'firebase-admin'
npm install
Cannot find serviceAccountKey.json

Download it from step 1 above. Must be named exactly serviceAccountKey.json in project root.

This member cannot receive notifications

User needs to:

  1. Open the app (login.html)
  2. Log in
  3. Click "Allow" when asked for notifications
  4. Token will be saved automatically
Notification not received
  • Check device notification settings
  • Make sure app has notification permissions
  • Try closing and reopening the app
  • Check internet connection
